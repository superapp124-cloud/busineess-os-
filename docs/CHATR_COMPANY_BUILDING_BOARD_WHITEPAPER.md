## 🛡️ ROUND 2: ENTERPRISE CIO QUESTIONS (SAFETY & RESILIENCE)

### 5. How do I migrate without disrupting my business?
**Sidecar Workflow Integration (Zero Big Bang).**  
CHATR attaches to **1 workflow only** (*Candidate Follow-up Only*) via webhooks while leaving SAP, Salesforce, and email 100% untouched. As confidence grows, additional workflows are activated incrementally.

### 6. What happens when CHATR executes 2,000 wrong invoices?
**Universal Rollback State Machine.**  
Every execution graph logs atomic inverse state transactions (`Do` → `Undo`). Clicking **`[Emergency Rollback]`** in Mission Control automatically dispatches inverse API calls (voiding invoices, notifying recipients, halting queues) and logs a root-cause explanation trace.

### 7. What happens during an outage (OpenAI / WhatsApp / SAP fails)?
**Local Fallback Models & Asynchronous Buffer Queue.**  
* If OpenAI fails → CHATR fails over to local Ollama / Llama-3 models.
* If SAP fails → Transactions buffer in local `BusinessObjectStore` state queues until SAP recovers, emitting zero dropped transactions.
