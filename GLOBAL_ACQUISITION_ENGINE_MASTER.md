## 6. Eliminating Friction: The Sub-5-Second Activation Rule

```mermaid
flowchart TD
    LAND["Visitor Arrives from Google or Direct Share"] --> VALUE["Experience Value First (No Signup Required)<br/>(Generate link, test simulator, make browser call)"]
    VALUE --> PROMPT["Natural Next Step: Save Link / Invite Team / Claim @username"]
    PROMPT --> AUTH{"Zero-Password 1-Tap Auth"}
    AUTH -->|Desktop| G["Google 1-Tap Login"]
    AUTH -->|Mobile| WA["WhatsApp 1-Tap OTP"]
    AUTH -->|iOS / Mac| AP["Apple Sign-In"]
    G --> INSIDE["Instantly Active in Workspace"]
    WA --> INSIDE
    AP --> INSIDE
    INSIDE --> EXPAND["Invite 3–10 Teammates (Viral B2B Seat Expansion)"]
```

1. **Never make customers type passwords:** Rely strictly on Google 1-Tap, WhatsApp OTP, and WebAuthn.
2. **Never gate the free utility:** Let visitors create the WhatsApp link or place the test call *before* prompting to register.
3. **Progressive Profiling:** Collect business details *after* value has been delivered, inside the active workspace.
