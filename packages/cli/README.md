# `@chatr/cli`

The official command-line interface for developing, testing, and publishing capabilities on CHATR Intent OS.

## CLI Design Principles
- **Human-friendly output by default.**
- **Machine-readable output via `--json` for CI/CD.**
- **Deterministic behaviour with stable exit codes.**
- **Actionable error messages with suggested fixes.**
- **No hidden side effects—commands should do exactly what they say.**
